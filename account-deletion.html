SAV Manager Pro – Account Deletion

Developer: TATAZ TECH

This page explains how SAV Manager Pro users can request deletion of their account and associated application data.

1. Delete your account from the application

  1. Open SAV Manager Pro.
  2. Go to Settings.
  3. Select Delete my account.
  4. Confirm the deletion when prompted.

Account deletion is permanent and cannot be undone.

2. If you no longer have access to the app

You may request account deletion by contacting the developer support email address below.

Support email: [oami.familly@gmail.com]

For verification, the request must be sent from the email address associated with your SAV Manager Pro account.

Data deleted

When an account deletion request is completed, the following data is deleted where applicable:

  • user account/profile;
  • associated company account when applicable;
  • technician accounts associated with that company when applicable;
  • customers;
  • equipment;
  • interventions;
  • stock data and stock movements;
  • other application data associated with the deleted company/account.

Retention

Deletion is definitive. If some data must be retained for legal, accounting, fraud prevention, or security reasons, it may be retained only for the legally required period and only for that purpose.
